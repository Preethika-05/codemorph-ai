# CodeMorph AI

CodeMorph AI is a complete Python web application for AI-assisted code translation. It includes private user accounts, secure password hashing, per-user saved translation history, a responsive browser interface, and a Flask JSON API.

## Features

- Translate between Java, Python, JavaScript, TypeScript, C, C++, C#, Go, Rust, PHP, Ruby, Kotlin, and Swift with Gemini.
- Register, log in, and log out. Passwords are stored as secure Werkzeug hashes, never as plain text.
- Save each successful translation to its owner's account and reload it from the history panel.
- Use SQLite automatically for local development and PostgreSQL in production.
- Health endpoint at `/health`; production sessions use secure cookie settings in the Render blueprint.

## Run locally

Requires Python 3.11 or newer and a Gemini API key.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:GEMINI_API_KEY = "your_api_key_here"
$env:SECRET_KEY = "a-long-random-secret-for-local-development"
python app.py
```

Open <http://127.0.0.1:8080>. Local user accounts and history are stored in `codemorph.db` (ignored by Git). Set `DATABASE_URL` to a PostgreSQL connection string if you want to run locally against PostgreSQL.

## Deploy to Render

The included `render.yaml` creates a Python web service and a PostgreSQL database, generates the session secret, configures secure cookies, and asks for the Gemini API key during setup.

1. Push this repository to GitHub.
2. In Render, choose **New → Blueprint** and select this repository.
3. Enter `GEMINI_API_KEY` when Render prompts for the secret, then deploy the blueprint.
4. Open the `codemorph-ai` web service in Render to copy its generated `https://…onrender.com` URL.

The deployment URL is generated by Render when the service is created. No Render account or deployment credentials are available in this workspace, so the service must be created from the Render dashboard before a live URL exists. The database is provisioned by the blueprint and its connection string is passed to the app.

## API

- `POST /api/auth/register` — `{ "name": "Ada", "email": "ada@example.com", "password": "at-least-8-chars" }`
- `POST /api/auth/login` — `{ "email": "ada@example.com", "password": "…" }`
- `POST /api/auth/logout` and `GET /api/auth/me`
- `POST /api/translate` — authenticated; accepts `sourceLanguage`, `targetLanguage`, `sourceCode`, and `includeExplanation`
- `GET /api/history` and `DELETE /api/history/<id>` — authenticated and scoped to the signed-in user
- `GET /api/languages`, `GET /health`

Set `GEMINI_API_KEY`, `SECRET_KEY`, and optionally `DATABASE_URL` and `GEMINI_MODEL` in the deployment environment. The default model is `gemini-3.8-flash`. Never commit credentials.
